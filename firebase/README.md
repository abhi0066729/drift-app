# Firebase MCP Integration Folder

Place your downloaded Firebase service account key file here as:
`service-account.json`

### How to get service-account.json:
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Open **Project Settings** -> **Service Accounts** tab
3. Click **Generate new private key**
4. Save the downloaded JSON file into this folder as `service-account.json`
